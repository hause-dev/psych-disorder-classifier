# Results
This folder contains csv files of the main results

`Best_Main_Feature_Combinations.csv` - The feature combinations producing the highest AUC value for each algorithm in each main disorder

`Best_Specific_Feature_Combinations.csv` - The feature combinations producing the highest AUC value for each algorithm in each specific disorder

`Logisticregression_Maindisorder_AEI_AUC.csv` - The average logistic regression AUC values and standard deviations for each main disorder for the dataset including age, education, and IQ, and for the one without 

`Logisticregression_Maindisorder_Average_AUC.csv` - The average logistic regression AUC values and standard deviations for each main disorder with PCA applied, and without

`Main_Disorder_Data.csv` - Contains the accuracy and AUC values of all of the models for every main disorder feature combination

`Main_Model_Average_AUC.csv` - The average AUC values and standard deviations of all of the main disorders for each machine learning algorithm with PCA applied, and without

`Specific_disorder_data.csv` - Contains the accuracy and AUC values of all of the models for every specific disorder feature combination

`Specific_Model_Average_AUC.csv` - The average AUC values and standard deviations of all of the specific disorders for each machine learning algorithm with PCA applied, and without
